forEach, map e filter

⭐ Fácil

📋 O que fazer:

Você já conhece forEach dos formulários. Agora vamos aprender map e filter — dois métodos que transformam arrays.

  • Dado o array: [3, 7, 12, 5, 20, 8, 15, 2]
  • Use map para criar um novo array com o dobro de cada número
  • Use filter para criar um novo array só com os números pares
  • Mostre os dois resultados na área de output

A diferença crucial:

  • forEach → percorre e não retorna nada (só executa)
  • map → percorre e retorna um novo array transformado
  • filter → percorre e retorna um novo array filtrado
O map e filter nunca alteram o array original — eles sempre criam um novo array. Isso é chamado de "imutabilidade" e é muito importante no React!

find e reduce

⭐ Fácil

📋 O que fazer:

Agora vamos usar find e reduce com um array de objetos:

  • Dado o array de produtos:
const produtos = [
    { nome: "Camiseta", preco: 49.90 },
    { nome: "Calça", preco: 129.90 },
    { nome: "Tênis", preco: 299.90 },
    { nome: "Boné", preco: 39.90 },
    { nome: "Jaqueta", preco: 189.90 }
];
  • Use find para encontrar o primeiro produto acima de R$100
  • Use reduce para calcular o total de todos os preços
  • Use filter para pegar todos os produtos abaixo de R$100
  • Mostre tudo no output

Diferença entre find e filter:

  • find → retorna o primeiro item que passa no teste (um objeto)
  • filter → retorna todos os itens que passam no teste (um array)
reduce é o mais poderoso: ele "reduz" um array inteiro a um único valor. Sintaxe: array.reduce((acumulador, item) => acumulador + item.preco, 0) — o 0 é o valor inicial do acumulador.

Destructuring (Desestruturação)

⭐⭐ Médio

📋 O que fazer:

Destructuring é um atalho para extrair valores de objetos e arrays. Em vez de acessar com obj.propriedade, você "abre" o valor direto:

  • Parte 1 — Objetos: Dado o objeto abaixo, extraia nome, idade e cidade usando destructuring 
const pessoa = { nome: "Gabriel", idade: 25, cidade: "BH", profissao: "Dev" };
  • Parte 2 — Arrays: Dado o array abaixo, extraia o primeiro e segundo item 
const cores = ["vermelho", "azul", "verde", "amarelo"];
  • Parte 3 — Em funções: Crie uma função que receba um objeto pessoa e use destructuring no parâmetro

Comparação lado a lado:

// ❌ Sem destructuring (modo antigo):
const nome = pessoa.nome;
const idade = pessoa.idade;

// ✅ Com destructuring (modo moderno):
const { nome, idade } = pessoa;
No destructuring de objetos, os nomes das variáveis devem corresponder às chaves do objeto. Para arrays, a posição é que importa.

Spread Operator (...)

⭐⭐ Médio

📋 O que fazer:

O spread operator (...) "espalha" os itens de um array ou objeto. É como abrir uma caixa e jogar o conteúdo fora dela:

  • Parte 1 — Combinar arrays: Junte os dois arrays abaixo em um só
const frontend = ["HTML", "CSS", "JavaScript"];
const backend = ["Node.js", "Python", "Java"];
  • Parte 2 — Copiar e modificar objeto: Copie o objeto abaixo e mude a cidade
const usuario = { nome: "Gabriel", cidade: "BH", nivel: "iniciante" };
  • Parte 3 — Adicionar item ao array sem mutar: Adicione "TypeScript" ao array frontend sem usar push

Por que não usar push?

// push ALTERA o array original (mutação):
frontend.push("TypeScript");

// spread CRIA um novo array (sem mutação):
const novoArray = [...frontend, "TypeScript"];
No React, você nunca deve mutar o estado diretamente. O spread é a ferramenta principal para atualizar arrays e objetos sem mutação. Aprenda agora e vai te salvar depois!

5

createElement + appendChild

⭐⭐ Médio

📋 O que fazer:

Até agora você mudou conteúdo que já existia na página (textContent, innerHTML). Agora vamos criar elementos do zero com JavaScript!

  • Dado o array: ["Maria", "João", "Ana", "Carlos", "Beatriz"]
  • Para cada nome, crie um <li> com document.createElement("li")
  • Defina o texto do <li> com .textContent
  • Adicione o <li> na <ul> abaixo com .appendChild()

O fluxo é sempre:

// 1. Criar o elemento
const li = document.createElement("li");

// 2. Configurar (texto, classes, atributos...)
li.textContent = "Maria";

// 3. Colocar na página
lista.appendChild(li);
O elemento só aparece na tela depois de usar appendChild. Antes disso ele existe só na memória do JavaScript!

    Remover Elementos + Event Delegation

    ⭐⭐⭐ Difícil

    📋 O que fazer:

    Expanda o desafio anterior: agora cada item deve ter um botão "✕" que o remove ao clicar.

    • Mesmo array: ["Maria", "João", "Ana", "Carlos", "Beatriz"]
    • Cada <li> deve conter: um <span> com o nome + um <button> com "✕"
    • Ao clicar no "✕", remova o <li> da página

    Conceito novo — Event Delegation:

    Em vez de adicionar um evento em cada botão, você adiciona um único evento na <ul> e verifica quem foi clicado:

    // ❌ Um evento por botão (ineficiente):
botao1.addEventListener("click", ...);
botao2.addEventListener("click", ...);

// ✅ Event Delegation (um evento para todos):
lista.addEventListener("click", (event) => {
    if (event.target.classList.contains("btn-remover")) {
        event.target.closest("li").remove();
    }
});
    event.target é o elemento exato que foi clicado. .closest("li") sobe na árvore do DOM até achar o <li> pai. Esse padrão é usado em frameworks como React por baixo dos panos!

      Mini To-Do List — Juntando Tudo!

      ⭐⭐⭐ Difícil

      📋 O que fazer:

      Este é o boss final! Crie uma To-Do List funcional usando tudo que aprendeu:

      • Input de texto + botão "Adicionar"
      • Ao clicar "Adicionar" (ou pressionar Enter):
        • Valide se o campo não está vazio
        • Crie um <li> com o texto da tarefa
        • Adicione um botão "✕" para remover
        • Limpe o input após adicionar
      • Ao clicar na tarefa (no texto), marcar como concluída (classe concluida)
      • Ao clicar no "✕", remover a tarefa
      • Mostrar contador: "X tarefa(s) pendente(s)"

      Ferramentas que você vai usar:

      • createElement + appendChild → criar itens
      • remove() → deletar itens
      • Event delegation → detectar cliques na lista
      • classList.toggle → marcar/desmarcar concluída
      • querySelectorAll + filter → contar pendentes
      Este é basicamente o projeto que todo dev faz ao aprender um framework como React. Você está fazendo com JS puro — quando for usar React, vai entender exatamente o que o framework automatiza pra você!
