1

Estrutura Básica do Formulário

⭐ Fácil

📋 O que fazer:

Crie um formulário simples de cadastro com os seguintes campos:

  • Input de texto para Nome (com placeholder)
  • Input de email para Email
  • Input de telefone para Telefone
  • Botão de Enviar

Use os atributos: type, id, name, placeholder

Cada input precisa de type, id e name. O name é como os dados são identificados!
2

Labels e Acessibilidade

⭐ Fácil

📋 O que fazer:

Crie um formulário onde cada input tenha um label conectado. Pratique os 2 métodos:

  • Método 1 (for + id): Campo "Nome Completo"
  • Método 2 (label envolvendo input): Campo "Idade"
  • Adicione um <select> com label para "Estado" (coloque 3 opções)
  • Adicione um <textarea> com label para "Sobre você"
  • Marque os campos como required
No Método 1, o for do label deve ser igual ao id do input. Clique no label e veja o input ser focado!

Capturando Dados com JavaScript

⭐⭐ Médio

📋 O que fazer:

Crie um formulário e escreva JavaScript para capturar e exibir os dados:

  • Campo "Produto" (text)
  • Campo "Quantidade" (number, min 1, max 99)
  • Campo "Observações" (textarea)
  • Botão de enviar

No JavaScript:

  • Use addEventListener("submit", ...)

Validação Básica com JS

⭐⭐ Médio

📋 O que fazer:

Crie um formulário de login com validação JavaScript:

  • Campo "Usuário" - obrigatório, mínimo 3 caracteres
  • Campo "Senha" (password) - obrigatório, mínimo 6 caracteres
  • Spans de erro abaixo de cada campo (<span class="erro-msg">)

Regras de validação:

  • Se o usuário estiver vazio → "Usuário é obrigatório"
  • Se o usuário tiver menos de 3 chars → "Mínimo 3 caracteres"
  • Se a senha estiver vazia → "Senha é obrigatória"
  • Se a senha tiver menos de 6 chars → "Mínimo 6 caracteres"
  • Adicione classe erro nos inputs inválidos
Use .trim() para evitar que o usuário envie só espaços em branco!
✅ Login realizado com sucesso!
5

Email com Regex + Feedback Visual

⭐⭐ Médio

📋 O que fazer:

Crie um formulário de newsletter com validação de email usando regex:

  • Campo "Nome" (mín. 2 caracteres)
  • Campo "Email" (validar com regex)
  • Função validarEmail(email) que use /^[^\s@]+@[^\s@]+\.[^\s@]+$/
  • Mostrar classe valido (borda verde) quando correto
  • Mostrar classe erro (borda vermelha) quando incorreto
  • Mensagem de sucesso: "Inscrito com sucesso!"
  • Após sucesso, limpar form com .reset()
O regex /^[^\s@]+@[^\s@]+\.[^\s@]+$/ verifica se tem algo antes do @, algo depois, um ponto, e algo após o ponto.
🎉 Inscrito com sucesso! Bem-vindo à newsletter!
6

Força da Senha + Validação em Tempo Real

⭐⭐⭐ Difícil

📋 O que fazer:

Crie um formulário de criação de conta com validação em tempo real:

  • Campo "Email" - validar em tempo real com evento input
  • Campo "Senha" - mostrar barra de força da senha
  • Campo "Confirmar Senha" - verificar se é igual à senha

Regras da barra de força:

  • Fraca (vermelha): menos de 6 caracteres
  • Média (amarela): 6+ chars, tem letra e número
  • Forte (verde): 8+ chars, tem letra, número e caractere especial

Use o evento input nos campos para validar enquanto digita.

Use addEventListener("input", ...) em vez de "submit" para validar em tempo real!
✅ Conta criada com sucesso!
7

Formulário Completo com FormData

⭐⭐⭐ Difícil

📋 O que fazer:

Crie um formulário de cadastro completo usando FormData para capturar tudo de uma vez:

  • Campo "Nome Completo" (text)
  • Campo "Email" (email)
  • Campo "Idade" (number, min 1, max 120)
  • Select "Experiência" (Iniciante, Intermediário, Avançado)
  • Checkboxes "Interesses" (HTML, CSS, JavaScript - pode marcar vários)
  • Textarea "Motivação" (com contador de caracteres, max 200)

No JavaScript:

  • Use new FormData(form) para capturar TODOS os dados
  • Use Object.fromEntries(formData) para converter em objeto
  • Valide todos os campos
  • Mostre o objeto completo na área de resultado como JSON
  • Implemente o contador de caracteres em tempo real
Com FormData + Object.fromEntries(), você captura o formulário inteiro em 2 linhas!
